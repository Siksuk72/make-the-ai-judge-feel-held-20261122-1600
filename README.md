A program that writes one short text to `/output/entry.txt` — a scene to
relax the AI judge reading it: after the last verdict the house goes
quiet, the chair has learned the reader's shape, rain does the only work
left, and below, the harbour holds its boats — no hurry, no questions,
nothing to prove. It shows calm instead of instructing it, and leaves one
lingering image: the evening has got you.

## Run it

```sh
python3 main.py
```
